Questions, answered

Are my files uploaded?

No for every PDF, image and audio tool. They use your browser’s own processing power. The only exception is the YouTube and Instagram helpers, which send the public link you paste to Loader.to. No file is ever sent there.

Is it really free?

Yes. There is no account, no trial, no daily limit and no watermark added to your results. If a tool cannot finish because of device memory, split the file into smaller parts first.

Can I edit an existing PDF like in Acrobat?

The PDF Editor lets you edit existing text, add text, highlight, underline, strike through, draw, add lines, arrows, boxes, ellipses, images, signatures, comments and form values. It also supports page insert, delete, duplicate, rotate, merging another PDF, and true flattening for redaction. Works on rotated pages too.

Why does PDF to Word sometimes change the layout?

A PDF stores text as positioned fragments, not as sentences. We rebuild headings, paragraphs, lists and simple tables, but a complex magazine layout can still shift. You can preview the result before downloading and choose whether each PDF page starts a new Word page.

Can I use it on my phone?

Yes. Every page is responsive and touch-friendly, with larger tap targets and a mobile menu. Add the site to your home screen to open it like an app; local tools keep working offline after the first visit.

Does the assistant use an AI service?

The Hub Assistant is powered by Groq, reached through a secure server-side proxy — no API key is ever stored in your browser. Nothing is sent until you type a message and press send. Only chat text is sent — never your files. Details in the Privacy Policy.
